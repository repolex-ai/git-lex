# Serve & visualize

```bash
git lex serve viz      # local web UI (picks a free port, opens your browser)
git lex serve sparql   # standard W3C SPARQL endpoint with a Swagger UI
```

The viz shows recent activity, an interactive graph of your documents and
their links, and an animated replay of your knowledge graph growing
commit by commit.
